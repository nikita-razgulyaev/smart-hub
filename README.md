# Smart Hub

Панель мониторинга умного дома — **чистый frontend, без backend и без базы данных**.

- **Стек:** React + TypeScript + Zustand + Tailwind CSS (Vite)
- **Внешние данные:** прямые запросы из браузера к бесплатным публичным API (без ключей)
- **"Умный дом":** комнаты, устройства, музыка, датчики, котировки — реалистичная локальная симуляция (эмулирует то, что раньше делал backend через Socket.IO), состояние тумблеров сохраняется в `localStorage`
- **Тесты:** Jest + React Testing Library

Раньше в проекте был backend на NestJS + PostgreSQL — он полностью убран. Всё,
что backend делал (эмуляция показаний датчиков, движения котировок,
проксирование внешних API), теперь происходит прямо в браузере: дешевле,
без БД, без хостинга сервера, деплоится как обычный статический сайт.

## Быстрый старт

```bash
cd frontend
npm install
npm run dev
```

Откройте http://localhost:5173 — дашборд открывается сразу, без логина.

## Сборка и тесты

```bash
npm run build   # продакшн-сборка в dist/
npm run test    # юнит-тесты (Jest + RTL)
npm run lint    # ESLint
```

## Структура

```
frontend/
├── src/
│   ├── api/external.ts     # прямые вызовы внешних API (см. таблицу ниже)
│   ├── data/seedData.ts    # стартовые данные комнат/устройств/музыки/акций
│   ├── hooks/useSimulation.ts  # локальная симуляция датчиков/музыки/котировок

│   ├── components/          # UI-компоненты (карточки, табы, графики)
│   └── pages/DashboardPage.tsx
└── public/
    ├── fonts/
    └── images/               # см. "Изображения" ниже
```

## Внешние API

Каждый источник, требующий сети, вызывается напрямую из браузера (все
перечисленные ниже поддерживают CORS и не требуют API-ключа) с fallback-цепочкой
на случай сбоя основного источника:

| Функция | Основной источник | Резервный источник | Если оба недоступны |
|---|---|---|---|
| Погода | Open-Meteo (+ их же geocoding для поиска города) | — | сообщение об ошибке в карточке |
| Курсы валют | cbr-xml-daily.ru (зеркало ЦБ РФ) | currency-api (fawazahmed0) | сообщение об ошибке |
| Статус дня (РФ) | isdayoff.ru | Nager.Date | локальный fallback "Рабочий день" |
| Факт "сегодня в истории" | Wikipedia REST (on this day) | — | локальный fallback-текст |

Комнаты, устройства, музыка, датчики, новости, котировки и график энергии — не
внешние API, а локальные данные (`src/data/seedData.ts`), которые "оживляются"
через `useSimulation` (случайное блуждание показаний/котировок, воспроизведение
музыки) — эмуляция реального умного дома без физического железа.

## Изображения

Кладите картинки в `frontend/public/images/` — Vite отдаёт всё из `public/` как
есть, обращаться к ним в коде нужно по абсолютному пути `/images/имя-файла`.
Сейчас вместо картинок используются эмодзи/градиентные заглушки (камеры,
лампа, обложка трека, новости) — пришлите файлы, и я подключу `<img>` с
нужными путями.

## Деплой

Проект — обычный статический сайт (результат `npm run build` — это просто HTML/CSS/JS
в `dist/`), backend и БД не нужны вообще. Подойдёт любой бесплатный статический
хостинг:

- **Vercel** / **Netlify** — Import Project → Root Directory `frontend` → Build
  command `npm run build` → Output directory `dist`
- **GitHub Pages** — `npm run build`, запушить содержимое `dist/` в ветку `gh-pages`
- **Cloudflare Pages** — аналогично Vercel/Netlify

Никаких переменных окружения, БД или сервера настраивать не нужно — все внешние
API вызываются напрямую из браузера пользователя.
